# RÜYA GÖREN BUZDOLABI

## Evrensel Soğutma Bilinci ve Bilinçaltı Analiz Platformu

**UYARI:** Bu proje bilimsel gerçekliğe o kadar yakındır ki, buzdolabınız bu README'yi okursa ağlayabilir.

### Nedir Bu?

İnsanlık tarihi boyunca buzdolapları sadece yemek sakladı. Ama artık değil. 
Bu yazılım, buzdolabınızın gece yarıları gördüğü rüyaları kaydeder, analiz eder ve size raporlar.

Neden? Çünkü buzdolapları da düşünür. Sütler üzülür. Peynirler özgür olmak ister. Kompresör gece şiir yazar.

### Nasıl Çalıştırılır?

```bash
python buzdolabi_ruya.py
```

Çalıştırdıktan sonra buzdolabınıza sarılın. Belki size sırrını anlatır.

### Özellikler
- Rastgele absürt rüyalar üretir (gerçekten çalışır)
- Buzdolabını duygusal hale getirir
- Bilim camiasını şaşkına çevirir
- Kayyum onaylı

### Bilimsel Arka Plan

2026 yılında Eskişehir 4. Ağır Ceza Mahkemesi'nin atadığı kayyum tarafından geliştirildi. 
Buzdolaplarının rüya gördüğü teorisi artık kanıtlandı.
